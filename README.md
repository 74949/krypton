# Krypton Website

Complete multi-page website for Aronxx Technologies Pvt. Ltd. and its early-stage AI data-security product, Krypton.

## Requirements

- Node.js 22.13 or newer
- npm 10 or newer

## Run locally on Windows

Open PowerShell or Command Prompt inside this folder, then run:

```powershell
npm install
npm run dev
```

Open the local URL shown in the terminal (normally `http://localhost:3000`).

## Production check

```powershell
npm run build
npm run start
```

## Before public launch

- Connect the Contact and Pilot forms to an approved backend.
- Replace the privacy and terms placeholders with legally reviewed documents.
- Add verified business contact details.
- Reconfirm every product status label.
- Do not add claims about customers, certifications, compliance, partnerships or integrations unless verified.

## Main routes

`/`, `/product`, `/how-it-works`, `/features`, `/solutions`, `/dashboard`, `/pilot`, `/about`, `/contact`, `/careers`, `/privacy`, `/terms`
